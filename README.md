Storm Runner is an original storm-chaser flight game: fly the SR-7 through
thunder rings, drop cargo on an island strip, rescue a stranded crew and land
in the calm eye of the tempest. Five missions across three regions, with fuel
that burns, lightning and turbulence that damage the hull, and a campaign with
stars, storm credits and hangar upgrades. Raw Canvas 2D with its own 3-D
projection — no library, no network, no build step.

## Run it

```sh
cd game
python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser.

Controls: Shift / Ctrl throttle, W / S pitch, A / D bank, G gear, C drop a
crate, P pause. Mouse clicks work on the menus.
